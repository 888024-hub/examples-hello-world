Globed WebSocket bridge

Connects Qunet WebSocket traffic to one configured Globed game-server TCP endpoint.

Endpoints

GET /healthz — checks whether the required environment variables are configured.

wss://YOUR-DEPLOY-HOST/ws/YOUR-TOKEN — authenticated binary WebSocket tunnel. Set this as the game server's advertised server_address.

What it changes

Qunet WebSocket frames contain one message each. Qunet TCP uses a four-byte little-endian length prefix on ordinary messages. The bridge converts these outer framing rules and leaves Qunet message payload bytes unchanged.

Required setup

Configure GLOBED_TCP_HOST, GLOBED_TCP_PORT, and a URL-safe GLOBED_PROXY_TOKEN (at least 24 characters). The actual game server must accept TCP connections, normally on port 4349.

The token appears in the advertised server URL, so treat it as an unlisted endpoint identifier, not a secret from people using the server. This bridge only connects to the one configured backend.
