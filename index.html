Globed main-server bridge

Routes a patched Globed client's selected game-server connection through WebSockets and converts Qunet framing for TCP.

Endpoints

GET /healthz — checks whether the token, host allowlist, and port allowlist are configured.

wss://YOUR-DEPLOY-HOST/ws/YOUR-TOKEN?target_hex=... — authenticated binary WebSocket endpoint used by the client patch.

Configuration

Set GLOBED_PROXY_TOKEN, GLOBED_ALLOWED_GAME_HOSTS, and GLOBED_ALLOWED_GAME_PORTS in Deno Deploy. The allowed hosts must include the actual gameplay-server addresses announced by the official main server.

The bridge does not change the official central server. A custom Globed client build is required to route gameplay connections through this endpoint.
