Globed WebSocket bridge

A fixed-destination, authenticated binary WebSocket tunnel to a configured Globed TCP server.

Endpoints

GET /healthz — reports whether required environment variables are configured.

GET /ws — upgrades to an authenticated binary WebSocket and relays bytes to the configured TCP backend.

Important compatibility note

This endpoint does not make the unmodified Globed client use WebSockets for gameplay. A client-side WebSocket transport adapter is required; it must reassemble incoming binary messages into a TCP-like byte stream.

Configure GLOBED_TCP_HOST, GLOBED_TCP_PORT, and GLOBED_PROXY_TOKEN in the deployment environment. Never put the token in a URL.
